# Changelog

Release highlights for the Folio design system and its Drawing DSL. Each entry links to the
full bilingual release notes. Historical notes live in `docs/releases/`; the note for the
current release stays at the repository root so packaging and release tooling can find it.

## V6.0 - 2026-08

Twenty-two generator-backed diagram types close the Drawing DSL program.

- Completed the twenty-two-type generator catalog: Pyramid, Org Chart, Loop Flywheel, Scatter, Gantt.
- Added deterministic semantic routing with eight patterns, confidence bands, and a readable trace.
- Added the folio / dark / terminal theme profiles, resolved from semantic roles and contrast-gated.
- Added render-layer output knobs for size, detail, audience, and variant.
- Added Mermaid and draw.io import plus CSV / TSV chart normalization with a fidelity ledger.

Full notes: [RELEASE_NOTES_V6.0.md](RELEASE_NOTES_V6.0.md)

## V4.3 - 2026-08

Three production notation grammars complete the seventeen-type registry.

- Added a coordinate-free Sequence grammar with bounded participants and stable ids.
- Migrated UML Class into the shared compiler, scene, profile, host, catalog, and artifact pipeline.
- Added the ER grammar with bounded entities, fields, and relationships.

Full notes: [docs/releases/RELEASE_NOTES_V4.3.md](docs/releases/RELEASE_NOTES_V4.3.md)

## V4.2 - 2026-08

Safe tabular authoring and bounded semantic detail for production data visualizations.

- Added deterministic local CSV / TSV import with explicit encoding, delimiter, and mapping contracts.
- Added fail-closed protection against remote resources, formula-like cells, and oversized inputs.

Full notes: [docs/releases/RELEASE_NOTES_V4.2.md](docs/releases/RELEASE_NOTES_V4.2.md)

## V4.1 - 2026-08

Verified, accessible diagram embedding for documents and presentation decks.

- Added A4, Letter, responsive HTML, and 16:9 slide host contracts with bounded safe areas.
- Added atomic HTML and PPTX embedding through named slots with content-addressed artifacts.

Full notes: [docs/releases/RELEASE_NOTES_V4.1.md](docs/releases/RELEASE_NOTES_V4.1.md)

## V4.0 - 2026-08

Authoritative contracts and a deterministic developer workflow for all fourteen diagrams.

- Added one authoritative authoring schema and a maintained minimal example per diagram type.
- Added registry-derived list and init commands plus compiler-backed validation with stable exit codes.
- Added atomic single rendering and deterministic, collision-safe batch rendering.

Full notes: [docs/releases/RELEASE_NOTES_V4.0.md](docs/releases/RELEASE_NOTES_V4.0.md)

## V3.4 - 2026-08

A deterministic, audited, and release-gated baseline for the fourteen-type drawing platform.

- Added fast and full CI gates for tests, catalog validation, visual comparison, and packaging.
- Added an approved fourteen-type visual baseline locking reading order, dimensions, and digests.

Full notes: [docs/releases/RELEASE_NOTES_V3.4.md](docs/releases/RELEASE_NOTES_V3.4.md)
