怎么读这套颜色

两层。色板是原始颜料，每个色值只写一次；角色是用途，指向色板。 模板只读角色，不读色板。改色板一项，所有引用它的角色一起变 —— 品牌红被五个角色共用，以前是靠把这个值写五遍。

命名由路径派生：color.text.primary 就是 --color-text-primary。一条规则，加角色只需想一个名字。
