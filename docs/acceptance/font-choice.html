字体选择对比

同一段内容，五种设置。用于决定 demo 图改用哪种字体。

为什么要换字体

demo 图当前用 Charter, Georgia, serif —— 两者都是系统字体，不在仓库中。 系统字体版本变化会改变字形抗锯齿，导致同样的构建在不同机器产生不同像素。

实测：同环境重建 = 0 像素差异；HEAD~1 版本 vs 当前环境 = 5,024 像素差异， 但差异全部微弱（无一超过 200 强度），无法从产物解释。

选一个仓库自带的字体即可根治。仓库内目前只有 Source Serif 4（1.1 MB）。

如何判断

行宽决定文本占用的横向空间。绿色表示与 Charter 相差 1.5% 以内，黄色 5% 以内，红色更多。

Source Serif 4 原尺寸窄 7%：视觉上字更小、行更短，但与仓库其他文档（用同一字体族）一致。

放大 8% 补偿后行宽接近 Charter，但字号变大，需确认是否符合设计意图。
