# 两个后续步骤的评估与实施方案

> 评估：用 box tree 精确测量重新判定布局算法必要性；把 box_inspector 接入 CI。
>
> 结论基于实测，不是推测。

**分支**：`dev/document-engine`
**起点**：`768b921`

---

## 一、测量结果（决定判断的基础）

### 精确测量：7 类文档 371 段落

| 类别 | 页数 | 段落 | 跨页 | widow | orphan | 孤立标题 |
|---|---:|---:|---:|---:|---:|---:|
| one-pager | 1 | 37 | 0 | 0 | 0 | 0 |
| letter | 1 | 18 | 0 | 0 | 0 | 0 |
| resume | 2 | 67 | 0 | 0 | 0 | 0 |
| changelog | 2 | 29 | 0 | 0 | 0 | 0 |
| long-doc | 7 | 69 | 0 | 0 | 0 | 1 |
| portfolio | 6 | 59 | 0 | 0 | 0 | 0 |
| equity-report | 3 | 92 | 0 | 0 | 0 | 0 |
| **合计** | **22** | **371** | **0** | **0** | **0** | **1** |

**缺陷率：1 / 371 = 0.27%**

### 测量过程中修正的两个误报

修正前测得 widow=5、orphan=5。逐项核查后发现**全部是误报**：

| 误报来源 | 现象 | 修正 |
|---|---|---|
| **短标签重复** | 表格标签「市值」「P/E」在页 1 与页 3 各出现，被当作跨页段落 | 要求段落 ≥2 行 |
| **非连续重复** | `{{数据}}` 在 31 处出现，跨页即算 spanning | 要求页号连续 |

修正后 widow=0、orphan=0。

**反向验证**：构造必然跨页的文档（页 1 尾 3 行 + 页 2 头 5 行），被正确识别为 1 个跨页段落，且**正确地不判为 widow**（末段 5 行）。

## 二、步骤 1 评估：重新判定布局算法

### 必要性：**低**

| 证据 | 数值 |
|---|---|
| 缺陷总数 | **1**（孤立标题） |
| 段落总数 | 371 |
| 缺陷率 | **0.27%** |
| 受影响文档 | 1 / 7 |

**判断**：**不值得自研布局算法。**

理由：
1. 缺陷率 0.27% —— 自研算法的复杂度远超收益
2. 唯一缺陷是 1 个孤立标题 —— 可用 CSS 规则修复
3. 这与 `layout_experiment` 先前的结论（`keep-the-backend`）**方向一致**，但现在**有了可靠证据**

**先前结论不可信的原因**：几何启发式饱和（报 6 个 widow），使得「缺陷多 → 值得自研」的判断建立在错误数据上。现在数据支持「缺陷极少」。

### 可行性：**高**

| 项 | 状态 |
|---|---|
| 精确测量能力 | ✅ `box_inspector.py` |
| 可重复 | ✅ 同一文档结果稳定 |
| 反向验证 | ✅ 构造用例可检出 |

### 建议：**不做自研，但做一件事**

用已有的精确测量**修复那 1 个缺陷**，并验证。

## 三、步骤 2 评估：box_inspector 接入 CI

### 必要性：**中**

| 理由 | 说明 |
|---|---|
| **防止测量退化** | 本轮发现两个误报，说明测量本身会出错 |
| **分页质量可见** | 当前只有 `layout_experiment` 手工运行 |
| **代价低** | 7 类文档约 15 秒 |

**但要注意**：`box_inspector` 需要 **HTML**（渲染 box tree），不是 PDF。CI 中需先构建。

### 可行性：**高**

| 项 | 实测 |
|---|---|
| 单文档耗时 | 约 2 秒 |
| 7 类总耗时 | 约 15 秒（可接受） |
| 依赖 | WeasyPrint（已在 CI 中） |

### 建议：**接入，但作为报告而非硬门禁**

理由：分页缺陷数**受内容影响**。同一模板，换更长的内容就会产生缺陷。作为硬门禁会因内容变化而失败。

## 四、实施方案

### 阶段 1：修复那 1 个孤立标题

| 步骤 | 内容 |
|---|---|

**验收**：`box_inspector` 显示孤立标题 = 0，且 `fidelity.py measure` 仍 7/7 SSIM 1.0000。

### 阶段 2：box_inspector 接入 CI（报告模式）

| 步骤 | 内容 |

**验收**：nightly 产出分页报告，缺陷数与本地一致。

### 阶段 3：记录结论

| 步骤 | 内容 |
|---|---|

**验收**：census 通过率不下降。
