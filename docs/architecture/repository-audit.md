# Repository audit: what is redundant, and what does not belong in Git

A scan of every tracked file, asking two questions: is this reachable, and does it
belong in the repository at all.

**Scope**: 1142 tracked files, 112 MB of history. Measured, not read.

---

## What was removed

257 files, **25.7 MB**, each verified before deletion.

| Item | Files | Size | Why it is safe |
|---|---|---|---|
| `docs/acceptance/assets/` | 248 | 24.4 MB | Every acceptance page embeds its images as `data:` URIs and has **zero** external `src=` references. No tracked script reads the directory. It is the source material for pages that already inlined it. |
| `scripts/fixture_map.py` | 1 | 12 KB | Superseded twice over: fixtures key on **raw placeholder text** (1227 such lines in the corpus), not the semantic keys this maps; and the mapping was reimplemented as a declared table in `scripts/document_ir/bridge.py`. |
| 8 overview PNGs in `assets/demos/` | 8 | 1.3 MB | Referenced by **no** tracked file -- not a doc, not a script, not CI. Intermediate images from earlier work. |

`scripts/fixture_map.py` is the one that needed a second look. It is a CLI with a
documented usage, so "nothing imports it" was not enough to condemn it; what
condemns it is that the fixtures stopped using its convention.

## Decisions worth taking

### 1. The two CJK fonts -- kept, on the owner's decision

`assets/fonts/LXGWWenKai-{Regular,Medium}.ttf`.

**The case for untracking them:**

- `AGENTS.md` states the policy: the packaged skill does not bundle them, and the
  skill downloads them from the official source before building Chinese documents.
- `.gitignore` already reasons this way about the same problem: *"WeasyPrint native
  libraries, resolved per platform and never committed"*.
- They are already in `origin/main`'s history, so untracking does not shrink a
  clone of the existing history -- it shrinks every checkout from now on.

**The cost, measured:**

- `build.py --verify` treats a missing font as an **ERROR**, not a warning.
- CI runs `build.py --verify`, and **has no font download step**. Untracking
  therefore breaks CI until one is added.
- The recovery command exists, in `SKILL.md`.

**Decision: kept.** A user who has not downloaded them cannot build a Chinese
document, and the fonts are the difference between the system working on a fresh
clone and not. The 48 MB buys that, and the policy note in `AGENTS.md` describes
what the *packaged* skill contains rather than what the repository tracks.

### 3. `references/archive/` -- 14 planning documents, 0.2 MB

Drawing-DSL plans and audits from v2 through v5. Thirteen are referenced by
nothing. The size is negligible and they are the record of how the DSL got to v6,
so this is a note rather than a finding.

## What the scan found healthy

- **`.gitignore` is doing its job.** Zero untracked files, 11283 ignored entries,
  and every ignored directory (`dist/`, `docs/audits/`, `docs/plans/`,
  `docs/superpowers/`, `build/`) verified to have **zero** tracked files.
- **No duplicate content outside the dead assets.** Every other repeated file was
  one of the 248.
- **No orphaned assets.** `scripts/vendor/elk.bundled.js` (1.5 MB),
  `assets/illustrations/*.webp` (1.4 MB) and `SourceSerif4Variable-Roman.ttf`
  (1.1 MB) are all referenced -- the font by 47 tracked files.
- **Fixtures are loaded by directory**, not by name: `corpus.py` globs `*.yaml`,
  so the 217 files no document names individually are all reachable.

## Reproduce

```bash
# the dead directory: pages embed their images, so nothing links the files
grep -L 'src="data:image' docs/acceptance/*.html        # every page embeds

# the orphan demos: no tracked file names them
git grep -l demo-corpus-overview -- ':!assets/demos/'

# ignored directories really are untracked
for d in dist docs/audits docs/plans docs/superpowers build; do
  echo "$d: $(git ls-files "$d" | wc -l) tracked"
done
```
