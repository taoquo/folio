<p align="center"><strong>Folio Drawing DSL V4.0</strong></p>
<p align="center">Authoritative contracts and a deterministic developer workflow for all fourteen diagrams.</p>

### Changelog

1. Added one authoritative detailed authoring schema and maintained minimal example for every registered diagram type.
2. Added registry-derived list and init commands with portable schema, fixture, profile, and format metadata.
3. Added compiler-backed text and JSON validation with stable diagnostics and documented exit codes.
4. Added atomic single rendering and deterministic collision-safe batch rendering with fail-closed cleanup.
5. Versioned Architecture semantic input as 3.0 while preserving compatible unversioned and expert DrawingPlan paths.
6. Added schema/runtime parity, migration, CLI, dependency, determinism, accessibility, and full output-matrix coverage.
7. Approved the metadata-only Architecture baseline update with exact visual parity across all fourteen diagrams.

### 更新日志

1. 为全部已注册图表类型增加独立的权威详细 Schema 与持续维护的最小示例。
2. 增加由注册表驱动的类型发现与初始化命令，并输出可移植的 Schema、样例、Profile 和格式元数据。
3. 增加基于正式编译边界的文本与 JSON 验证，提供稳定诊断结构和明确退出码。
4. 增加原子化单图渲染与确定性、无命名冲突、失败闭合的批量渲染。
5. 将 Architecture 语义输入正式版本化为 3.0，同时保留兼容的无版本输入与专家 DrawingPlan 路径。
6. 增加 Schema/运行时一致性、迁移、CLI、依赖、确定性、可访问性与完整输出矩阵测试。
7. 在十四类图表视觉完全一致的前提下，批准 Architecture 仅元数据变化的基线更新。
